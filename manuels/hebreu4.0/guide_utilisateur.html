1. Flux de travail quotidien

ÉtapeAction
1. Modifier le contenuÉditer ou ajouter des .docx dans votre dossier documents\
2. Générer et vérifierDouble-cliquer sur lancer.cmd — le site s'ouvre dans le navigateur
3. PublierDouble-cliquer sur MAJ_GITHUB.cmd — publication sur GitHub Pages

2. Organisation des documents sources

documents\
├── Grammaire\
│   ├── Lecon01.docx          → lien dans la rubrique Grammaire
│   └── Lecon02.docx
├── Vocabulaire\
│   └── Mots_courants.docx
└── Chants\
    ├── __partition_Ave.docx  ← préfixe __ = partition musicale
    └── __correspondance.csv  ← associe partition + lien YouTube

Règles de nommage

ConventionDescription
Nom libre.docxDocument normal — apparaît comme lien dans le menu
__partition_NOM.docxPartition musicale — génère un PDF avec boutons YouTube
__correspondance.csvAssociation partition ↔ lien YouTube (dans le même dossier)

3. Générer le site (lancer.cmd)

  1. Ouvrir C:\SiteGITHUB\Hebreu4.0\
  2. Double-cliquer sur lancer.cmd
  3. Attendre la fin — le navigateur s'ouvre sur http://localhost:3500
  4. Vérifier le résultat
lancer.cmd supprime html\ à chaque génération pour éviter les fichiers résiduels.

4. Publier sur GitHub Pages (MAJ_GITHUB.cmd)

  1. Double-cliquer sur MAJ_GITHUB.cmd
  2. La fenêtre affiche les 4 étapes : sync → génération → commit → push
  3. Confirmer le push si demandé
  4. Le site est en ligne en 1 à 2 minutes sur https://guytitt.github.io/Hebreu4.0/

5. Ajouter ou modifier du contenu

Ajouter un document

  1. Copier le .docx dans le dossier documents\ voulu
  2. Lancer lancer.cmd — le document apparaît automatiquement
  3. Vérifier, puis MAJ_GITHUB.cmd

Supprimer un document

  1. Supprimer le .docx (et le .pdf correspondant)
  2. Relancer lancer.cmd puis MAJ_GITHUB.cmd

6. Partitions musicales

  1. Nommer le fichier : __partition_NomDeLaPartition.docx
  2. Créer __correspondance.csv dans le même dossier :
pdf_name,youtube_url
nom_de_la_partition.pdf,https://youtube.com/watch?v=XXXX

Lancer lancer.cmd — un PDF avec boutons YouTube et Jouer ici est généré automatiquement.

7. Si quelque chose ne fonctionne pas

ProblèmeSolution rapide
Le site ne se génère pasLancer python prog\versions.py pour diagnostiquer
PDF non généréVérifier que PDFCreator est installé et configuré
Push GitHub échoueVérifier token dans prog\config.yaml — voir guide de maintenance
Modules manquantsLancer python package\prog\remplace.py puis python package\prog\installer.py
