1. Installation initiale (nouvelle machine)

Prérequis : Python 3.11+, Node.js, PDFCreator, accès internet, GitHub Desktop.
⚠️ Pare-feu Windows — étape obligatoire
Lors du premier push GitHub, Windows peut bloquer git-credential-manager.exe.
Avant le premier push : ouvrir le Pare-feu Windows Defender → Paramètres avancés → Règles de trafic sortant → Nouvelle règle → Programme → parcourir jusqu'à git-credential-manager.exe → Autoriser.
Chemin typique : C:\Program Files\Git\mingw64\bin\git-credential-manager.exe
Sans cette autorisation : le push échoue avec "Impossible de se connecter au serveur distant".
  1. Installer GitHub Desktop et se connecter à son compte GitHub
  2. Cloner le dépôt via GitHub Desktop : https://github.com/GuyTitt/Hebreu4.0
  3. Dézipper le package dans C:\SiteGITHUB\Hebreu4.0\
  4. python package\prog\installer.py — crée C:\virpy13 + bibliothèques
  5. Éditer prog\config.yaml (voir section 2)
  6. python package\prog\remplace.py — déploie programmes ET manuels
  7. python prog\versions.py — vérifie l'installation
  8. Autoriser git-credential-manager.exe dans le pare-feu (voir encadré ci-dessus)
  9. lancer.cmd — premier test

2. Configuration (prog\config.yaml)

Ce fichier est personnel. Ne jamais le commiter sur git.
racine_source     = C:\MonDossier\documents     # sources DOCX
racine_site_local = C:\SiteGITHUB\Hebreu4.0    # dépôt git local
lancer_cmd        = C:\SiteGITHUB\Hebreu4.0\prog\lancer.cmd
url_github        = https://github.com/GuyTitt/Hebreu4.0
github_token      = ghp_VOTRE_TOKEN_ICI         # token PAT GitHub
github_user       = votre_login_github
branche           = main
message_commit    = auto
confirmation_git  = true

Obtenir un token PAT : github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → cocher repo.

3. Mise à jour des modules

3.1 Modifier un programme

  1. Éditer package\prog\genere_site_v25.5.py
  2. Renommer en genere_site_v25.6.py
  3. Mettre à jour version = ("genere_site.py", "25.6") dans le fichier
  4. Ajouter # v25.6 : description en tête
  5. python package\prog\remplace.py

3.2 Modifier un manuel

  1. Éditer package\manuels\hebreu4.0\maintenance_v1.1.html
  2. Renommer en maintenance_v1.2.html
  3. python package\prog\remplace.py — déploie vers manuels\hebreu4.0\maintenance.html

3.3 Archiver un ancien fichier

Déplacer dans package\prog\archive\ ou package\manuels\archive\ — remplace.py ignorera ces dossiers.

5. Déploiement multi-postes

  • Même structure C:\SiteGITHUB\Hebreu4.0\ sur chaque machine
  • Token GitHub propre à chaque utilisateur dans son config.yaml
  • Autoriser git-credential-manager.exe dans le pare-feu sur chaque poste
  • Partager le ZIP package pour synchroniser les versions
